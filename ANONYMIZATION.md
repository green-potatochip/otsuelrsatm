# Anonymous review artifact

This folder contains only the supplementary project page, its source, and
recorded experiment data. It has no repository history or remote configuration.
The manuscript PDF and reference video are not packaged.

Preparation covers source comments, visible labels, identifiers, directory
names, plain JSON, decompressed experiment JSON, and rebuilt static assets.
In-house sequence directories and matching manifest/code references use the
neutral identifiers `inhouse_htp_01` through `inhouse_htp_04`.
Compressed bundles are repacked with no filename or creation timestamp in
the gzip header. Numerical measurements and rendered geometry are preserved.

Personal workspace paths, institutional identifiers, original site references,
and development provenance are excluded. External author/contact/repository
fields are absent from the project package metadata. No analytics, author
profile links, or externally hosted runtime assets are required.

Public benchmark labels, standard graphics algorithm names, and third-party
dependency license notices are retained
for attribution. These identify public datasets and dependency authors rather
than the authors of this submission.

The preparation report is `submission-check.json`. Anonymous GitHub connection,
access settings, expiry settings, and the generated sharing link are configured
by the repository owner after upload. The folder contains no Git credentials.
